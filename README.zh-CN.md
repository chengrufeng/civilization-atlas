# 华夏人物图鉴 · Civilization Atlas

> 一张交互式地图，在时间与空间中追踪历史人物与事件——从三国起步，贯穿中华五千年，最终延伸至世界文明。

## 愿景

历史从来不是一份年表。它是一张由人、地点和事件交织而成的锦缎。**Civilization Atlas** 的存在，就是为了让这张锦缎变得可见——让你一眼看到历史发生在何处、谁在场、一个人的命运如何与下一个人相连。

本项目从**三国时期（184–280 年）**起步——那是谋士辈出、群雄逐鹿、决定中华文明走向的传奇年代。但这只是起点。

未来的蓝图：

- **中华上下五千年** —— 从黄帝与夏商周，到秦皇一统、盛唐气象、宋代理学、郑和下西洋，直至近现代
- **世界历史** —— 每一片大陆上崛起与衰落的帝国，从美索不达米亚到罗马，从蒙古西征到两次世界大战
- **跨文明连接** —— 丝绸之路、香料贸易、思想沿着无国界的路径传播流转

每一个曾经活过的人，每一个曾经改变世界的事件，在这张地图上都有一席之地。我们正朝着这个方向构建。

## 功能特性

- **交互式时间轴** —— 拖动年份，地图实时重组。历史不是静止的，呈现它的方式也不应该是。
- **人物与事件定位** —— 每个人物和事件都标注在真实发生地。放大看一场战役，缩小看一个时代。
- **人物关系网络** —— 可视化历史人物之间的连接。盟友、对手、师徒、亲缘——历史背后的人际网络。
- **事件轨迹追踪** —— 在地图上追踪关键人物的行踪。曹操北征、诸葛亮北伐——一步步跟随他们的足迹。
- **阵营视觉体系** —— 魏、蜀、吴，各有独立的视觉标识。
- **智能标签避让** —— 标签根据缩放级别和空间密度自适应调整，即使最密集的事件地点也能清晰可读。

## 技术栈

- **Leaflet** —— 轻量高性能交互地图
- **原生 JavaScript** —— 无框架、无构建步骤，打开 `index.html` 即可使用
- **自定义数据层** —— 结构化历史数据，设计上可跨时代、跨文明扩展

## 快速开始

```bash
git clone git@github.com:chengrufeng/civilization-atlas.git
cd civilization-atlas
# 因使用 ES Modules，需通过本地服务器访问（直接打开 index.html 会触发 CORS）
npx serve .          # 或 python3 -m http.server 8080
# 然后在浏览器打开 http://localhost:8080
```

无构建步骤，但需一个本地 HTTP 服务器（ES Modules 不支持 file:// 协议）。

## 参与贡献

历史浩瀚，没有一个人能穷尽所有。如果你在某个时代有专长——无论是战国百家争鸣、罗马帝国兴衰，还是明治维新——你的知识都能为这张地图增添一笔。

- **数据贡献** —— 人物、事件、坐标、关系
- **纠错建议** —— 发现日期、地点或归属有误？提一个 Issue。
- **功能想法** —— 什么能让这张地图对学生、教育者或历史爱好者更有用？
