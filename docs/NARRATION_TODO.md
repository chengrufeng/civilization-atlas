## 📈 单人物制作时间预估

| 阶段 | 时长 | 备注 |
|---|---|---|
| 数据补全 + validate | 10-20 分钟 | 若 events 已完备则跳过 |
| 写脚本 JSON | 30-60 分钟 | 13-17 段文案，需打磨 |
| 跑 build-narration | 1-2 分钟 | edge-tts |
| 加 keywords + 抓图 | 5-10 分钟 | Bing 后端 |
| 本地化图片 | 1 分钟 | 工具自动 |
| 浏览器实测 + 调整 | 15-30 分钟 | 修文案 / 调特效 / 修史实 |
| 录屏 + 剪辑 | 30 分钟 | OBS + 字幕校对 |
| **合计** | **约 2 小时 / 人物** | 流程化后可压缩 |
